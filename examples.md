# Filled examples

Three-paragraph aim prompts pre-filled for common game shapes. On normal
invoke the skill runs (or composes) these directly — you shouldn't need
to paste them.

## Brotato-like arena survivor / Phaser

```text
I want you to build a top-down arena survivor at the level of Brotato. It
should be utterly perfect, visually beautiful, with every single thing
done at AAA-indie quality, from combat feel to sprite readability to
anything you could think of.

Fan out sub-agents and have sub-agents tackle each one individually so
that the game is utterly perfect. Have a separate sub-agent check it
visually to ensure it reads as clearly as Brotato. That separate sub-agent
should be a really harsh critic, and if it doesn't read that well, it
should keep going.

Don't stop until each sub-agent is utterly wowed with the quality when
compared with actual Brotato screenshots. It should literally compare
them side by side blind and say which one looks better. Do this in
Phaser. Fan out sub-agents.
```

## Noun cheat sheet

| Genre | REFERENCE | AREA_1 / AREA_2 | STACK |
|---|---|---|---|
| Arena survivor | Brotato | combat feel / sprite readability | Phaser |
| Roguelike | Hades | combat feel / lighting | PixiJS or Godot |
| FPS | Call of Duty | textures / physics | THREE.js or Babylon |
| Platformer | Celeste | movement feel / hitbox clarity | Phaser or PixiJS |
| Bullet-hell | Vampire Survivors | wave density / readability | Phaser |

If the model can obviously beat `REFERENCE` on day one, pick a harder one.
The bar is meant to be unreachable — that's the point.
